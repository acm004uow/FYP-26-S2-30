# System Admin User Stories

1. As a System Admin, I want to create user accounts for new Managers, so that they can access the task allocation system and manage staff and tasks.

2. As a System Admin, I want to create user accounts for Department Staff, so that they can submit task requests and allocate tasks within their department.

3. As a System Admin, I want to manage user roles and permissions, so that users have appropriate access levels based on their responsibilities, including assigning, modifying, and revoking roles.

4. As a System Admin, I want to reset user passwords, so that users can regain access to the system quickly and securely.

5. As a System Admin, I want to monitor security logs, including login attempts, failed authentications, and unauthorized access, so that I can detect and respond to security threats.

6. As a System Admin, I want to deactivate user accounts, so that inactive or departed staff cannot access the system.

7. As a System Admin, I want to configure global system parameters, including workload thresholds, proximity radius, and priority weights, so that the system operates according to organizational policies.

8. As a System Admin, I want to view audit logs, so that I can track all system activities, including user actions, task creations, allocations, and updates, and troubleshoot issues.
